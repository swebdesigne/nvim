# Java Development in Neovim

## Overview

Эта конфигурация Neovim настроена для полноценной разработки на Java с использованием **nvim-java** — современного LSP-клиента для Java.

## Установленные компоненты

| Компонент | Версия | Назначение |
|-----------|--------|------------|
| **jdtls** | 1.54.0 | Java Language Server |
| **lombok** | 1.18.46 | Поддержка Lombok аннотаций |
| **java-test** | 0.43.2 | Тестирование Java кода |
| **java-debug** | 0.58.3 | DAP отладчик |
| **spring-boot-tools** | 1.55.1 | Поддержка Spring Boot |
| **JDK** | 25 | Java Development Kit |

## Горячие клавиши и команды

### Управление проектом

| Команда | Описание |
|---------|----------|
| `:JavaSettingsChangeRuntime` | Смена Java runtime в проекте |

### Запуск и отладка приложений

| Команда | Описание |
|---------|----------|
| `:JavaRunnerRunMain` | Запуск основного класса (main method) |
| `:JavaRunnerStopMain` | Остановка запущенного приложения |
| `:JavaRunnerToggleLogs` | Переключение логов приложения |
| `:JavaRunnerSwitchLogs` | Переключение между логами разных приложений |
| `:JavaProfile` | Открыть UI профилирования |

### Тестирование (java-test)

| Команда | Описание |
|---------|----------|
| `:JavaTestRunCurrentClass` | Запустить все тесты в текущем классе |
| `:JavaTestDebugCurrentClass` | Отладить все тесты в текущем классе |
| `:JavaTestRunCurrentMethod` | Запустить текущий тестовый метод |
| `:JavaTestDebugCurrentMethod` | Отладить текущий тестовый метод |
| `:JavaTestRunAllTests` | Запустить все тесты в проекте |
| `:JavaTestDebugAllTests` | Отладить все тесты в проекте |
| `:JavaTestViewLastReport` | Показать отчет последнего запуска тестов |

### Отладка (DAP)

| Команда | Описание |
|---------|----------|
| `:JavaDapConfig` | Настроить DAP конфигурацию |

## Автоматические команды (при открытии Java файла)

### Форматирование
- Форматирование через LSP: `<leader>f`
- Форматирование диапазона: `:-format`

### Диагностика
- `gd` — перейти к определению
- `gD` — перейти к объявлению
- `gi` — перейти к реализации
- `gt` — перейти к определению типа
- `gR` — показать ссылки на символ
- `<leader>D` — показать диагностику буфера
- `df` — показать диагностику текущей строки
- `K` — показать документацию (hover)

### Рефакторинг (через LSP команды)
- `<leader>rn` — переименовать символ
- `<leader>vca` — доступные код-экшены

## Настройка проекта

### Структура проекта
```
your-java-project/
├── src/
│   ├── main/java/
│   └── test/java/
├── pom.xml          (Maven)
└── build.gradle     (Gradle)
```

### Запуск
1. Откройте корневую директорию проекта в Neovim
2. Убедитесь, что открыт Java файл (`.java`)
3. jdtls автоматически подключится к проекту

### Выбор Java версии
Используйте команду `:JavaSettingsChangeRuntime` для выбора Java runtime из доступных. 

**Как проверить:**
1. Откройте любой Java файл в проекте (например, `Main.java`)
2. Подождите, пока jdtls запустится (проверьте `:LspInfo` — должен отобразиться jdtls)
3. Выполните `:JavaSettingsChangeRuntime` — появится список runtime с выбором JDK

**Настройка автоматически добавляется при первом подключении jdtls.**

## Дополнительные возможности

### Lombok support
Поддержка Lombok включена по умолчанию (версия 1.18.46). Если нужно обновить:
1. Скачайте новую версию с https://projectlombok.org/download
2. Положите `.jar` файл в `~/.config/nvim/java/`
3. Обновите путь в `lua/vniia/java-config.lua`

### Отладка
- Установите брекпоинты: `:lua require('dap').toggle_breakpoint()`
- Запустить отладку: `:lua require('dap').continue()`
- Остановить: `:lua require('dap').terminate()`

## Troubleshooting

### jdtls не подключается
- Убедитесь, что в проекте есть `pom.xml` или `build.gradle`
- Перезапустите LSP: `<leader>lr`
- Проверьте логи: `:lua print(vim.inspect(vim.lsp.get_log_path()))`

### Lombok не работает
- Проверьте, что файл `lombok-*.jar` есть в `~/.config/nvim/java/`
- Убедитесь, что версия совместима с jdtls 1.54.0

### Ошибки при тестировании
- Убедитесь, что в проекте есть зависимости для тестов (JUnit, TestNG)
- Проверьте, что тестовые файлы находятся в `src/test/java/`
